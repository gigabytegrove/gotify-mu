# Monita v1.1.7

Monita 1.1.7 adds first-class image messages to Chat Channels.

## Chat image messages

In a Chat Channel, use the attachment button beside the composer to select one or more photos, optionally add text, and press **Send**. The images are stored with the message and displayed inline in the conversation.

- JPEG, PNG, GIF, and WebP are supported.
- Up to eight images can be attached to one message.
- Each image may be up to 25 MiB, with a 50 MiB combined limit per message.
- Text is optional when at least one image is attached.
- Selected images can be removed before sending.
- Desktop users can also drag images into the composer or paste images from the clipboard.
- Image metadata is present before realtime delivery, preventing the recipient-side race where a message could arrive before its photo.
- Attachment access remains authenticated to Channel members.

The capability endpoint advertises `chatImages: true` so Monita for Android and future clients can expose the feature only when the connected server supports it.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.

## Companion clients

Monita for Android v0.3.11 consumes the `chatImages` capability and provides native photo selection, authenticated inline rendering, and compatible notification previews.
