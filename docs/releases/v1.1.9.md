# Monita 1.1.9

Monita 1.1.9 adds first-class image delivery for Notification Channels.

## What changed

- Notification Channels accept authenticated multipart messages with inline JPEG, PNG, GIF, and WebP attachments.
- Image-bearing Notification messages preserve their explicit title.
- Home Assistant-originated Notification messages are delivered as push notifications rather than user Chat messages, so the account that owns the Home Assistant client token still receives the alert.
- Channel owners and administrators do not need a redundant membership row to use the direct image path.
- `/api/mu/v1/capabilities` advertises `notificationImages: true`.

## Compatibility

- Monita for Home Assistant 1.6.0 detects the new capability and sends camera/image bytes directly to Notification Channels.
- On Monita 1.1.8 and older, Monita for Home Assistant 1.6.0 falls back to the text alert instead of dropping the entire notification when an image is requested.
- Existing Chat image behavior remains unchanged.
