# Monita 1.3.4

Released: 2026-10-01

Monita 1.3.4 completes the canonical branding rollout for installed PWAs.

## Fixed

- Invalidates the previous PWA application-shell cache.
- Forces installed Monita PWAs to fetch the canonical 2026-10-01 logo and icon SVG assets already used by the server and Web UI.
- Keeps the supplied SVG masters unchanged.

## Compatibility

- No database migration is required.
- No API or client protocol changes are required.
- Monita for Android 0.3.15 and Monita for Home Assistant 1.8.2 remain compatible.
