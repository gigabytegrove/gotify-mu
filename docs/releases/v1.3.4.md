# Monita 1.3.4

This patch release makes the standalone Monita icon background transparent while preserving the supplied icon artwork exactly.

- Removes only the gray 512×512 background rectangle from the icon SVG.
- Leaves all logo/icon artwork, gradients, colors, proportions, paths, clipping, and embedded image data unchanged.
- Propagates the transparent icon to the Web UI, PWA, documentation, and release assets.
- No database or protocol changes.
