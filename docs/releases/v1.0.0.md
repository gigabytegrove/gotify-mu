# Gotify MU v1.0.0

Gotify MU 1.0.0 is the first stable release of the multi-user Gotify server fork.

It promotes the completed v0.5 platform and adds the final interoperability work for Home Assistant and MU-aware Chat clients.

## Highlights

- Shared, Global, and role-based Channels with Groups and multi-user delivery.
- Chat Channels using the established member-posting model.
- MU capability discovery and a separate realtime MU event stream.
- Typing presence, mention candidates, targeted `@username` notifications, and sender self-notification suppression.
- Home Assistant connections through either a Long-Lived Access Token or native `gotify-mu-ha` pairing.
- One-time native pairing codes, encrypted bridge credentials, repair without prematurely dropping a working bridge, and authenticated unpair/revoke.
- MFA, passkeys, LDAP/AD, service accounts, session controls, and audit/security administration.
- Webhooks, MQTT, schedules, escalations, Quiet Hours, Digests, Email, SMTP, RSS/Atom, Syslog, and iCal.
- Replies, threads, reactions, mentions, assignment, resolve/reopen, acknowledgements, attachments, templates, and saved searches.
- Plugin trust/catalog/update/uninstall, backup/restore, diagnostics, retention, and hardened managed updates.

## Compatibility

Existing Gotify application tokens, client tokens, `/message`, `/application`, and `/stream` behavior remain supported. MU-aware client features are additive and use separate discovery/realtime endpoints.

Database changes remain additive. Back up the persistent data directory and Gotify MU encryption key before upgrading.

## Release validation

The release candidate must pass the repository's full validation workflow: Web UI build, Go formatting/lint, complete tests, repository consistency checks, production Docker build with tests enabled, filesystem/container vulnerability scans, and SPDX SBOM generation. Publication then creates release checksums, provenance, and GHCR images.
