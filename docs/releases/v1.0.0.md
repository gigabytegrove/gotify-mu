# Gotify MU v1.0.0

Gotify MU 1.0.0 is the first stable release of the multi-user Gotify server fork.

It promotes the completed v0.5 platform and adds the final interoperability work required for the 1.0 baseline: native Home Assistant pairing and first-class Chat Channel support for MU-aware clients.

## Highlights

- Shared, Global, and role-based Channels with Groups and multi-user delivery.
- First-class Notification and Chat Channel types.
- MU capability discovery and a separate realtime MU event stream.
- Typing presence for Chat Channels without changing the stock Gotify message stream.
- Home Assistant connections through either a Long-Lived Access Token or native `gotify-mu-ha` pairing.
- One-time native pairing credentials with encrypted bridge secrets.
- MFA, passkeys, LDAP/AD, service accounts, session controls, and audit/security administration.
- Webhooks, MQTT, schedules, escalations, Quiet Hours, Digests, Email, SMTP, RSS/Atom, Syslog, and iCal.
- Replies, threads, reactions, mentions, assignment, resolve/reopen, acknowledgements, attachments, templates, and saved searches.
- Plugin trust/catalog/update/uninstall, backup/restore, diagnostics, retention, and hardened managed updates.

## Compatibility

Existing Gotify application tokens, client tokens, `/message`, `/application`, and `/stream` behavior remain supported. MU-aware client features are additive and use separate discovery/realtime endpoints.

Database changes remain additive. Back up the persistent data directory and the Gotify MU encryption key before upgrading.

## Validation gate

The 1.0 release candidate is required to pass:

- Web UI build and formatting
- Go lint
- complete Go test suite
- repository consistency checks
- production Docker build with tests enabled
- filesystem/dependency and container vulnerability scans
- SPDX SBOM generation
- release checksums and provenance during publication

Live deployment should preserve the existing data mount and environment configuration and retain the pre-upgrade backup until acceptance is complete.
