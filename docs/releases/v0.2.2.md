# Gotify MU v0.2.2

**Release date:** 2026-09-25  
**Status:** Pre-release

Gotify MU v0.2.2 fixes the update-screen refresh loop introduced in v0.2.1 and makes the update process visible from start to finish.

## Software Update

The Software Update screen now shows:

- overall percentage complete
- the current update stage
- timestamped activity
- download progress
- installation progress
- restart and verification progress
- successful completion
- automatic recovery when an update cannot be completed safely

The activity shown in the Web UI is intentionally written for administrators using the product. Low-level service commands and internal diagnostics stay in server logs.

## Refresh-loop fix

v0.2.1 could continuously reload Settings after an update because the updater's completed state persisted across page reloads.

v0.2.2 only reloads the page when an update started in the current page session and then reaches completion. A previously completed update does not trigger another reload.

The update-status poller is also stable now. It no longer recreates itself after every status response.

## Interface language

Visible product language was simplified:

- preview version instead of development build
- automatic updates instead of managed updater
- password sign-in instead of local authentication
- single sign-on instead of protocol names where the protocol name is not needed
- internal commit/build details removed from the Dashboard
- unfinished security roadmap items removed from Settings

## Compatibility

The multi-user data model and Gotify-compatible client/API behavior are unchanged.
