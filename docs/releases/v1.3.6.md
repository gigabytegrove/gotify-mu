# Monita 1.3.6

Released: 2026-10-02

Monita 1.3.6 restores the newly supplied Monita icon exactly as provided and makes that artwork the enforced source for current Web/PWA icon surfaces.

## Branding

- `assets/source/Monita_Full-01.svg` remains the full Monita logo master.
- `assets/source/Monita_IconOnly-01.svg` is restored from the newly supplied app/icon master.
- The supplied gray icon canvas/background is preserved.
- Web, PWA, favicon, Apple touch icon, Microsoft tile icon, and mobile-header icon aliases resolve to the supplied icon artwork.
- Desktop header branding continues to use the supplied full Monita logo.
- The PWA no longer declares the icon as maskable artwork.
- Branding and PWA cache versions are advanced so older cached variants are discarded.

## Artwork integrity

Monita does not redraw, recolor, crop, trace, simplify, remove the canvas/background, or otherwise reinterpret the supplied artwork.

## Compatibility

- No database migration is required.
- No API or protocol changes are required.
- Existing deployments can update in place.
