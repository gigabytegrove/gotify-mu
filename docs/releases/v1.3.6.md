# Monita v1.3.6

Monita v1.3.6 packages the naming cleanup and Web UI/UX refresh merged after v1.3.5.

## Highlights

- Monita is now the primary active product identity across runtime, configuration, CLI, connector, audit, plugin, and security surfaces.
- `MONITA_*` is the primary environment-variable namespace.
- Legacy `GOTIFY_*` and `GOTIFY_MU_*` environment variables remain accepted where required for upgrade compatibility.
- Fresh installations now prefer `data/monita.db`; existing `data/gotify.db` installations are detected and retained automatically.
- The Web UI receives a new control-surface theme with refreshed navigation, header, login, cards, controls, spacing, and typography.
- The Appearance selector is hidden from Settings while existing stored/system theme behavior remains compatible.

## Compatibility notes

Protocol-level compatibility identifiers that would break existing clients if renamed, including `/gotifyinfo` and required upstream Go package references, remain intentionally available. These are compatibility internals rather than active Monita branding.

No manual database migration is required for existing installations.
