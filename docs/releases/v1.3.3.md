# Monita 1.3.3

Released: 2026-10-01

Monita 1.3.3 is the canonical branding refresh for the server, Web UI, and PWA.

## Branding

- Installs the supplied `Monita_Full-01.svg` as the authoritative full Monita logo.
- Installs the supplied `Monita_IconOnly-01.svg` as the authoritative Monita application/icon mark.
- Uses those vectors directly anywhere SVG is supported.
- Updates the desktop header, PWA icon, favicon/static assets, repository documentation, release assets, and compatibility image paths.
- Retains legacy PNG filenames only where existing paths may depend on them; those PNGs are faithful raster renders of the supplied vectors.
- Invalidates the previous PWA shell cache so installed clients refresh the new branding.

## Compatibility

- No database migration is required.
- No API or client protocol changes are required.
- Existing URLs, persisted data, and compatibility identifiers are unchanged.
