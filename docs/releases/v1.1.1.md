# Monita v1.1.1

Monita 1.1.1 makes normal installation and updating substantially faster.

## Faster installation

Docker Compose now uses the published Monita container image by default. A normal installation no longer needs to compile the Web UI and server on the machine running Monita.

## Faster updates

When an update is started from **Settings → Software Update**, Monita downloads the published release image, verifies that it matches the selected release, applies it, and checks that the updated service is healthy.

## Local development

Building from source is still supported for development and troubleshooting through the optional Docker Compose build override.

Existing persistent data is unchanged by this update.
