# Monita v1.1.3

Monita 1.1.3 restores Channel image management to the normal Channel editing workflow.

## Improved

- The **Edit Channel** dialog now shows the current Channel image.
- Upload or change a Channel image directly while editing the Channel.
- Remove a custom Channel image directly from the editor.
- Existing image-management shortcuts remain available from the Channel action menu.
- Channel managers can use edit and image-management controls that match their server-side permissions.
- Security-sensitive and destructive Channel actions remain limited to Channel owners and administrators.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update** using the single-container updater.
