# Monita 1.3.2

Released: 2026-10-01

Monita 1.3.2 fixes a Web/PWA shell rendering defect introduced with the new PWA metadata.

## Fixed

- Removed literal `\\n` escape text that could render above the Monita header.
- Restored the PWA/meta tags to normal HTML source lines.
- Invalidated the previous PWA shell cache so installed clients receive the corrected HTML immediately.
- Preserves the Monita 1.3.1 desktop notification toasts, conversation UI, mentions, and PWA behavior.

## Compatibility

- No database migration is required.
- No client protocol changes are required.
- Monita for Android 0.3.13 remains compatible.
- Monita for Home Assistant 1.8.0 remains compatible.
