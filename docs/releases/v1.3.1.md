# Monita 1.3.1

Released: 2026-10-01

Monita 1.3.1 is a focused desktop/PWA notification usability update on top of 1.3.0.

## Realtime on-screen notifications

Incoming realtime messages now create a visible in-app toast in the Monita desktop Web UI and installed PWA.

Each toast identifies:

- whether the source is a Chat or Notification Channel
- the Channel name
- the sender when available
- a short message preview
- whether the current user was explicitly mentioned

An **Open** action takes the user directly to the originating Channel or Chat.

These in-app notifications work independently of browser or operating-system notification permission. Existing browser notifications and notification sounds remain supported.

## Compatibility

- No database migration is required.
- No client protocol changes are required.
- Android 0.3.13 remains compatible with Monita 1.3.1.
- Existing Gotify-compatible clients remain supported.
