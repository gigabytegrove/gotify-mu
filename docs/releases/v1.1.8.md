# Monita v1.1.8

Monita 1.1.8 makes administrator sessions substantially less disruptive without removing step-up protection from sensitive actions.

## Administration without constant re-authentication

A normal authenticated administrator session can now view and refresh the routine administration UI without elevation. This includes user and Group lists, audit history, security-policy values, operations/status, sessions, service-account metadata, integration/connector status, schedules, escalation rules, and the plugin catalog.

Channel owners and managers can also view Channel member and assignment information without elevating.

Step-up authentication is still required when an action changes access, secrets, security posture, system state, or destructive data. Examples include changing users or roles, modifying Channel membership, changing the security policy, creating/revoking service credentials, revoking sessions, installing updates, changing integrations/connectors, downloading full backups or diagnostics, restoring data, and destructive actions.

## Longer, consistent elevation window

The default administrative re-authentication duration is now **8 hours** for installations that have not explicitly saved another value. Existing saved security-policy values are not overwritten.

The browser no longer hard-codes a one-hour request. It uses the effective duration supplied by the server, and all supported authentication paths apply the same server-side maximum:

- local password + MFA
- LDAP / Active Directory
- passkeys
- OIDC

The elevation dialog also shows the effective unlock duration.

## Faster updater visibility

The release workflow now publishes the validated self-update runtime, checksums, release tag, and GitHub Release before the slower Docker image/archive export finishes. This means **Settings → Software Update** can discover v1.1.8 sooner. Prebuilt container archives are attached to the same release afterward.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.
