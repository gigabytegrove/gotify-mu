# Monita v1.1.8

Monita 1.1.8 makes administrator re-authentication a true step-up security control instead of a constant obstacle during normal administration.

## Administrator sessions

A signed-in administrator can now view normal administration pages and perform routine, non-destructive configuration without repeatedly entering a password or passkey.

This includes normal access to users, audit history, security policy, operations, sessions, service-account metadata, Groups, integrations, schedules, escalations, connectors, update status, and the Plugin Catalog. Routine creation and editing of Groups, integrations, schedules, escalations, connectors, and Channel membership settings also stays available during the normal admin session.

## Step-up authentication

Re-authentication is still required for higher-risk actions, including:

- changing or deleting users
- deleting Channels or changing Channel ownership/security
- removing Channel members or Group assignments
- changing passwords, MFA, or passkeys
- changing the server security policy
- backup, restore, and diagnostics exports
- revoking sessions
- creating/changing service-account credentials
- regenerating secrets or Home Assistant pairing credentials
- installing software updates
- destructive deletion of Groups, integrations, schedules, escalations, or connectors

## Elevation duration

When no explicit security policy has been saved, the default step-up window is now **4 hours**. The Web UI uses the configured policy value instead of always requesting one hour.

Existing installations that explicitly saved a different **Administrative re-authentication duration** keep that configured value.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.
