# Monita v1.1.8

Monita 1.1.8 makes administration much less disruptive while preserving step-up authentication for genuinely sensitive actions.

## What changed

Normal authenticated administrators can now **view** administrative pages without repeatedly re-entering credentials. This includes users, audit history, security policy, operations, sessions, service accounts, Groups, integrations, schedules, escalations, connectors, the Plugin Catalog, and update status.

Channel owners/managers and administrators can also inspect Channel membership and assignment information without elevation.

## What still requires elevation

Step-up authentication remains required for security-sensitive operations such as:

- deleting or changing users and permissions
- changing Channel ownership or security
- adding/removing members or Group assignments
- changing passwords, MFA, or passkeys
- creating/revoking service-account tokens
- regenerating integration secrets
- revoking sessions
- backup, restore, diagnostics, and audit export
- changing the security policy
- installing plugins or Monita updates
- destructive delete operations

## Elevation duration

The default administrative elevation window is now **4 hours** on installations that have not explicitly saved another value. If an administrator has configured a different value under **Admin → Security & Operations**, Monita continues to honor that value.

The Web UI now reads the configured duration from the server instead of always requesting a hard-coded one-hour elevation.

OIDC sign-ins now use the same session-inactivity and elevation policy as local, LDAP, and passkey authentication.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.
