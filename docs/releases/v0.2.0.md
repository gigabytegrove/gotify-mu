# Gotify MU v0.2.0

**Release date:** 2026-09-24  
**Status:** Pre-release

Gotify MU v0.2.0 is the first formal release baseline for the fork as its own multi-user notification platform while retaining Gotify protocol and client compatibility.

## Highlights

### Real multi-user Channels

A Gotify application can now function as a shared Channel with a canonical owner plus multiple assigned users. Shared users can receive and read the same stored message without duplicating it per account.

Global Channels can automatically include every current and future user.

### Safer shared-message lifecycle

v0.2.0 adds per-user mute, archive, and restore behavior while keeping destructive operations explicit. Global Channel message deletion, full-history clearing, and Channel deletion are administrator-only.

### Gotify MU Web UI

The inherited Gotify interface has been replaced with a Gotify MU-oriented Web UI featuring:

- Dashboard
- unified Messages and Archive
- Channel directory and management
- user administration
- user display names
- Groups
- Clients
- Plugins
- Audit Log
- Settings
- responsive navigation
- light, dark, and system appearance modes
- search/filter controls throughout the administrative UI

### Plugin installation from the browser

Administrators can upload a compatible Gotify plugin `.so` directly from **Plugins → Install Plugin** after re-authentication. Plugins are stored in the persistent plugin directory and loaded immediately.

Because Gotify plugins execute native code in the server process, only trusted binaries should be installed.

### Security and identity foundation

This release introduces user display names, User Groups, and an administrative/security Audit Log foundation. It also improves expired elevation handling in the browser.

MFA/2FA, passkeys, LDAP/Active Directory, richer session policy, and advanced role/group policy are planned next-generation features, not part of v0.2.0.

### Experimental Chat Channels

The server and Web UI can optionally allow assigned Channel members to post messages and preserve sender identity.

The official Gotify Android client still remains receive-only for this feature. A dedicated Gotify MU Android fork is planned before Chat Channels are treated as a complete mobile feature.

## Compatibility

Gotify MU v0.2.0 intentionally retains:

- Gotify application tokens
- Gotify client tokens
- `/application`
- `/message`
- `/stream`
- normal Gotify Android notification reception
- the upstream Go module path required for plugin compatibility

Database migration remains additive.

## Upgrade notes

Back up the persistent data directory/database before upgrading.

For manual Docker installations using the current project layout, keep the existing data mount and rebuild/recreate only the application image/container.

Do not delete or replace the persistent data directory during an upgrade.

## Known limitations

- Chat sending is not available from the stock Gotify Android app.
- MFA/2FA and LDAP/AD are not yet implemented.
- Group-based Channel/policy assignment is not yet implemented.
- Audit coverage will continue expanding.
- Plugin binaries must match the server's Go/plugin ABI and architecture.
- This is a pre-1.0 release and should be validated in the target environment before production rollout.
