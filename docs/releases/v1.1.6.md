# Monita v1.1.6

Monita 1.1.6 completes Channel image management for both new and existing Channels.

## Channel images

- **Create Channel** now includes an optional Channel image picker.
- A selected image is previewed before the Channel is created and can be changed or removed before saving.
- Existing Channels retain image management in **Channels → ⋮ → Edit channel**.
- Existing Channels also retain the direct image shortcuts in the Channel action menu.
- Supported formats are PNG, JPG, JPEG, and GIF.

If the Channel itself is successfully created but its image upload fails, Monita keeps the Channel and its token and reports that the image can be added from **Edit Channel**. This avoids duplicate Channels caused by retrying the entire creation operation.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.
