# Monita 1.3.0

Released: 2026-10-01

Monita 1.3.0 focuses on the desktop experience, Progressive Web App support, Chat presentation, mention alerts, and product-name cleanup.

## Desktop conversation workspace

Chat Channels now open as real conversations rather than generic notification cards. The desktop view includes:

- left/right message bubbles based on sender
- sender identity and timestamps
- day separators
- highlighted `@username` mentions
- image and attachment collaboration content
- reactions, replies, threads, and enabled per-message workflow controls
- typing status
- conversation search
- active/archive switching
- a persistent message composer with drag/drop, paste, image previews, and mention autocomplete

Notification Channels keep their operational-feed presentation.

## Progressive Web App

The Web client is now an installable PWA. Monita registers a service worker, provides standalone manifest metadata, exposes an install action when supported, and caches the application shell and static same-origin assets.

Authenticated API responses are not cached by the service worker.

## Mention notifications

Realtime Chat messages now carry canonical Monita mention metadata. The Web/PWA client recognizes both the new metadata and legacy metadata on older messages.

When the signed-in user is tagged, the browser notification identifies that they were mentioned and opens the relevant Channel.

## Branding

User-facing Web labels now identify the product as Monita. Compatibility names remain only where they are required for existing Gotify-compatible clients, environment variables, persisted data, or protocol continuity.

## Compatibility

- Existing data is unchanged.
- Existing Gotify-compatible clients remain supported.
- Existing Channel and message APIs remain compatible.
- Monita for Android 0.3.13 is the companion phone-test release for the new mention-notification and per-Channel sound behavior.
