# Monita 1.3.5

This patch release corrects the visible Monita application branding so the Web UI uses the supplied canonical artwork instead of a reconstructed text treatment.

- Desktop/tablet application header uses the supplied canonical full Monita logo.
- Mobile application header uses the supplied canonical standalone Monita icon.
- Browser favicon, Apple touch icon, Microsoft tile icon, and PWA manifest icon use the canonical standalone icon.
- Branding asset URLs are versioned and the PWA shell cache is advanced so stale logo/icon files are discarded on update.
- No logo or icon geometry, gradients, colors, typography, proportions, or embedded artwork are redrawn or otherwise modified.
- No database or protocol changes.
