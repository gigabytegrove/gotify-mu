# Monita 1.3.5

Released: 2026-10-02

Monita 1.3.5 makes the newly supplied Monita artwork the authoritative branding across the server, Web UI, PWA, documentation, and release assets.

## Branding

- Uses the supplied `Monita_Full-01.svg` as the full Monita logo.
- Uses the supplied `Monita_IconOnly-01.svg` as the application/icon mark.
- Preserves the supplied icon canvas/background exactly.
- Does not redraw, recolor, crop, trace, simplify, remove the background, or change artwork geometry.
- Existing stable asset filenames are retained only as visual aliases so application paths remain compatible.
- Installed PWAs receive a new shell-cache version so stale artwork is discarded.

## Compatibility

- No database migration is required.
- No API or protocol changes are required.
- Existing installations can update in place.
