# Monita v1.1.5

Monita 1.1.5 prevents the browser from continuing to display an older Web UI after an in-app update.

## Fixed

- The Web UI entry document is now explicitly served with no-cache headers.
- After an in-app update, the browser receives the frontend bundled with the newly installed Monita runtime instead of reusing an older cached page.
- The Channel image controls restored in 1.1.3 are therefore visible immediately after updating without requiring a manual hard refresh.

## Channel image controls

Channel owners, administrators, and Channel managers can manage the Channel image from **Channels → ⋮ → Edit channel**. The editor shows the current image with **Upload image** or **Change image** and **Remove image** controls. The Channel action menu also retains image-management shortcuts.

## Updating

Monita 1.1.2 and newer can install this release from **Settings → Software Update**.
