# Monita v1.1.2

Monita 1.1.2 replaces the updater-worker design with true single-container software updates.

## One container

Monita now performs software updates from the main application itself. Updating from the Web UI does not create an updater sidecar or temporary update container.

## Faster updates

Monita downloads the published runtime for the server architecture, verifies the download, installs it into persistent Monita data, and restarts itself in place.

There is no local application compile during a normal update.

## Persistent updates

The active updated runtime is stored with Monita's persistent data so normal container restarts continue using the installed version.

## Deployment

The standard Docker Compose configuration no longer mounts the Docker socket because Monita no longer needs Docker access to update itself.

Existing application data is unchanged by this release.
